    Flow rules

    • Token resolves to one process instance + one customer; nothing else is reachable.
    • Upload allowed when status is Requested, Submitted (replace) or Rejected (resubmit).
    • Approved documents are locked.
    • View / download works while the link is valid and not every document is approved.
    • Once all are approved the portal shows a completion screen; files are no longer exposed.

    Gaps vs. today NEW

    • Rejection reason is not persisted today (only a toast). Needs a column / lookup FK on the tracking record.
    • Signed token (process instance key + customer mapping id + expiry, HMAC / Data Protection), validated on every portal call; "resend" issues a new token.
    • Anonymous, rate-limited portal endpoints on the shared API.
    • "Send link" email through SendPurchaseAgreementEmailAsync with a {{UploadLink}} merge token.
